## 当前基线

- K230：GC2093 原始 `640×480` 采集，内部缩放 `320×240` 做传统 Blob 识别；不使用 YOLO。
- 控制：K230 每帧经有线 UART 发送标定后的 `x_cm_x100` 给 Ti；PC 图传不参与任何控制。
- 图传：从原始图裁取 `640×240` 管子带，JPEG `Q80` / 目标 `8 FPS`，PC 最近邻 2 倍显示；已实测 K230 `Loop 25.7–26.7 FPS`、图传 `6.8–8.2 FPS`。
- 标定：真实 1 cm 钢球已完成台架五点初测：`cx=(47.19,102.57,160.47,221.28,270.67)` 对应 `(-10,-5,0,+5,+10 cm)`。相机最终装车后必须重新复验。

新接手者先阅读 [文档总览与交接](文档/README.md)；图传烧录与验收见 [K230 热点图传操作手册](文档/K230热点图传操作手册.md)。

## 目录约定

- `k230_code/`：唯一 K230 部署入口与归档诊断脚本。
- `k230_libs/`：UART 协议参考实现。
- `pc_receiver/`：PC 图传接收、显示与录像。
- `ti_reference/`：Ti/MSPM0 控制参考骨架，非可直接烧录工程。
- `文档/`：当前交接、TODO、装配、标定、图传和验收资料。
- `reference_code/`：队友提供的历史参考代码；不得替代比赛入口。
