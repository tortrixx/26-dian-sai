## 当前基线

- K230：GC2093 原始 `640×480` 采集，内部缩放 `320×240` 做传统 Blob 识别；不使用 YOLO。
- 控制：K230 每帧经有线 UART 发送标定后的 `x_cm_x100` 给 Ti；PC 图传不参与任何控制。
- 图传：最新模式从原始图裁取 `640×240` 管子带，JPEG `Q80` / 目标 `5 FPS`，PC 最近邻 2 倍显示；等待实机性能验收。
- 标定：真实 1 cm 钢球已完成台架五点初测：`cx=(47.19,102.57,160.47,221.28,270.67)` 对应 `(-10,-5,0,+5,+10 cm)`。相机最终装车后必须重新复验。
