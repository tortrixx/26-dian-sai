### 1.1 K230 视觉、UART 与图传

部署文件：`k230_code/k230_final.py`。

当前实机配置：

```text
GC2093 640×480 全视场采集
  -> 内部 320×240 全帧缩放
      -> 传统亮/暗 Blob + 形状门限 + α-β 跟踪
      -> UART：标定后的 x_cm_x100
      -> 图传：原始帧裁取管子带 640×240 / JPEG Q80 / 目标 8 FPS
  -> PC TCP 显示与录像（不参与控制）
```

实测（PC 已连接；视觉首测时已使用真实 1 cm 钢球）：

| 指标 | 已测范围 | 结论 |
| --- | --- | --- |
| K230 `Loop` / UART 更新 | 23.4–27.3 FPS | 适合进入钢球闭环标定 |
| PC 图传（旧基线） | 6.6–7.8 FPS，320×240 | 已确认可显示，但刻度细节不足 |
| 管子细节图传（新配置） | 640×240、Q80、目标 8 FPS | 已完成代码与 PC MP4 静态验证，待 K230 实机验收 |

| `net` | 约 0.1–0.3 ms | 当前不是网络瓶颈 |

### 1.2 UART 协议与 Ti 控制骨架

- 二进制协议已统一，格式见 [控制接口骨架.md](控制接口骨架.md)。

- `firmware_state_machine_skeleton.c` 已有帧校验、序号门限、PD、回中位和端部救球逻辑，但它是**参考骨架**，尚未合入真实 MSPM0 工程。

### 1.3 已排除路线

当前 Yahboom CanMV v1.4.3 不可用：

```text
CH0 YUV420SP -> VENC H.264
CH1 RGB565   -> 传统视觉
```

实机探针会在 `Sensor.set_framesize()` 报：`'Sensor' object has no attribute 'buf_init'`。不要把 `VIDEO_BACKEND` 改为 `h264_hw`，也不要部署 `k230_h264_dual_stream_probe.py`。详见 [H264图传测试说明.md](H264图传测试说明.md)。

## 2. 当前限制与禁止事项

- 已完成首轮真实 1 cm 钢球五点标定（按 `-10/-5/0/+5/+10 cm`）：内部 `cx=(47.19,102.57,160.47,221.28,270.67)` 与物理厘米 `(-10,-5,0,5,10)` 采用分段线性插值，五个标定点精确对齐；面积门限 `40..140 px`、标称面积 `78 px`。仍须在最终机械固定后做一次全五点复验才可用于正式闭环成绩。
- 无球环境可能出现偶发高质量 Blob；接入舵机前，Ti 必须保持无效帧/超时回中位保护。
- PC 图传、热点和接收端不得回传任何控制数据。
- 图传最新模式已从原始 640×480 帧取 640×240 管子带；先验收刻度是否清晰、K230 `Loop` 是否 ≥20 FPS，再决定是否把图传降到 4 FPS。
- 不要为了提高图传 FPS 改回 640×480 视觉或提高 JPEG 发送频率；这会直接降低控制更新率。
- 旧脚本仅供参考，比赛入口始终是 `k230_final.py`。

## 3. 下一步执行顺序

### P0：摆管、Ti/MG996 与供电装配（当前主线）

详细硬件执行顺序见 [下一阶段装配与联调清单.md](下一阶段装配与联调清单.md)。

1. 完成摆管铰点、MG996 连杆/摇臂、端部防落球和相机支架；空载下确认机械行程不顶死。
2. 舵机使用独立大电流电源；K230、MSPM0/Ti、舵机三者仅共地，禁止由 Ti 板小电源直接带舵机。
3. 按 [控制接口骨架.md](控制接口骨架.md) 合入 Ti UART/DMA、100 Hz 控制任务与 50 Hz PWM 钩子。
4. **无球、无闭环**完成舵机中位、脉宽限幅、正负方向、200 ms 视觉超时回中位和 UART 坏帧保护。

### P1：最终安装后的视觉复验（阻塞钢球闭环）

详细现场操作见 [钢球视觉标定操作.md](钢球视觉标定操作.md)。

1. 相机最终固定到车架后，保持全视场侧视近似正对摆管平面；在 `±8°` 摆角确认管子全程可见。**相机位置、焦距或安装角度一旦变化，现有标定表即失效。**
2. 在 `-10、-5、0、+5、+10 cm` 人工放置正常未喷涂钢球；每点保存 `cx`、`cy`、`pixels`、`quality` 和截图。
3. 更新 `k230_final.py` 的 `POSITION_CAL_PX/POSITION_CAL_CM` 五点表；当前程序用分段线性插值，不再只使用单一比例。
4. 用实测面积更新 `MIN_BLOB_PIXELS`、`MAX_BLOB_PIXELS`、`BALL_PIXELS_NOMINAL`；按实际管子位置更新 `PIPE_ROI`。
5. 在无球、强反光、短遮挡和轻振动下验证：无球不得连续输出有效位置；记录位置噪声。

完成条件：位置误差和噪声符合 `文档/测试与验收清单.md`，并把数据填入 `文档/测试记录表.csv`。

### P2：Ti/MG996 钢球闭环

1. 将 `firmware_state_machine_skeleton.c` 合入 Ti 工程，补齐硬件 PWM 与 UART/DMA 钩子。
2. MG996 使用独立大电流电源；K230、Ti、舵机电源共地，禁止从 Ti 小电源直接驱动舵机。
3. 无球校准中位脉宽、最大/最小脉宽及“正脉宽使钢球向哪侧移动”的符号。
4. 先验证：停止 K230、拔 UART、坏校验帧、无球时 Ti 在 200 ms 内按限速回中位。
5. `Ki=0`，按 `Kp -> Kd` 顺序完成 `-5/0/+5 cm` 静态测试，再开放动态 AB。

### P2：车体联调与比赛任务

遵循固定阶段：`IDLE -> STATIC_BALL -> DYN_AB -> DYN_LAP_CENTER -> DYN_LAP_TARGET`。前一阶段验收不通过，不开放后一阶段；动态失败优先降低车速/摆幅并检查位置延迟，不能先盲目提高增益。
