# 1 cm 钢球视觉标定操作

适用入口：`k230_code/k230_final.py`。本流程使用普通未喷涂的 1 cm 钢球，不使用 YOLO、不在水管上增加标记或传感器。

## 0. 安全与环境

1. 标定期间不要让舵机带动水管：拔掉舵机电源，或让 Ti 保持禁用/回中位安全状态。
2. 固定相机、焦距、支架和光源；保持当前 `640×480` 全视场，确保水管在 `-8°、0°、+8°` 都完全可见。后续一旦改变安装位置或焦距，必须重新标定。
3. 让管子先保持水平。物理中心为 `0 cm`，自行约定左负右正，并在所有记录中保持一致。

## 1. 先确认能识别到球

当前程序以局部亮度同时搜索亮 Blob 和暗 Blob：镜面钢球即使因反光变亮、或因阴影变暗，均可成为候选；随后由面积、宽高比、可用时的圆度和连续位置进行筛选。

1. 保持 `VISION_PROFILE = "fast_qvga"` 和 `STREAM_PROFILE = "control"`，不要为了看清画面改成 VGA 视觉。
2. 将钢球放在管子中央附近，运行 K230。
3. PC 图像应出现红色候选框、绿色十字和 `x=... q=...`；终端不应持续显示 `NO BALL`。
4. 看蓝色 `PIPE_ROI` 框：它必须完整覆盖钢球在管内的活动带，但不要大到包含大量车架、地面或背景。当前临时值是 `(10, 68, 300, 110)`，坐标基于内部 **320×240** 图像。

若没有框到钢球，依次只调整一项后重测：先调 `PIPE_ROI`，再把 `MIN_BLOB_PIXELS` 暂时降到 `5`、`MAX_BLOB_PIXELS` 放宽到 `300`，最后把 `L_CONTRAST_MARGIN` 从 `12` 改到 `8` 或 `16`。不要一开始同时改多个参数。

## 2. 收集五点原始数据

`k230_final.py` 已提供默认关闭的终端标定汇总。先改：

```python
CALIBRATION_ENABLE = True
CALIBRATION_LABEL = "-10cm"  # 每一个物理点改一次
```

将钢球的**球心投影**依次人工对准 `-10、-5、0、+5、+10 cm` 刻度。每个点静止约 5–8 秒，记录至少两行类似下面的终端输出：

```text
[CAL] -10cm n=60 cx=84.23 cy=121.14 px=37.6 wh=6.10x6.04 q=83.2 sx=0.18px
```

记录表：

| 物理位置 cm | `cx` px | `cy` px | `px` 面积 | `wh` | `q` | `sx` px |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| -10 |  |  |  |  |  |  |
| -5 |  |  |  |  |  |  |
| 0 |  |  |  |  |  |  |
| +5 |  |  |  |  |  |  |
| +10 |  |  |  |  |  |  |

- `cx/cy/px/wh/q` 是有效 Blob 的原始平均值；`sx` 是该窗口内 `cx` 的标准差。
- 每个点的两行结果应接近；若 `sx > 1 px`、框跳到背景或偶发 `NO BALL`，先解决光照/ROI/面积门限，不能直接拿数据拟合。
- `cx` 使用的是内部 320×240 坐标，**不是**相机 640×480 坐标；不能乘以 2 后再填入。

完成采集后将 `CALIBRATION_ENABLE` 改回 `False`，避免比赛运行时额外打印。

## 3. 拟合像素到厘米

先对五组数据拟合线性关系：

```text
x_cm = (cx - ZERO_X_PX) / PX_PER_CM
```

计算方式（用五点全部参与）：

```text
a = Σ[(cx_i - mean(cx)) × (x_cm_i - mean(x_cm))] / Σ[(cx_i - mean(cx))²]
PX_PER_CM = 1 / a
ZERO_X_PX = mean(cx) - mean(x_cm) / a
```

将结果写入 `VISION_PROFILES["fast_qvga"]` 的第 5、6 个参数：

```python
"fast_qvga": (640, 480, 320, 240,
               ZERO_X_PX, PX_PER_CM, PIPE_ROI, ...)
```

如果实际“右为正”，但球向右时 `cx` 变小，则 `PX_PER_CM` 必然为负；这是相机镜像方向导致的正常拟合结果，**不要强行改正号**。应以 `+5 cm` 时程序显示约 `+5.00 cm` 为准。

每一点再代回公式，记录残差：`预测位置 - 人工位置`。五点最大绝对残差建议不大于 `0.3 cm`；若超出，先检查相机是否斜视、管子是否水平、刻度是否按球心对准。摆角范围扩大或相机安装改变后应重新做多角度验证。

若相机与管子的机械位置已固定、线性拟合仍有稳定的透视残差，优先在 `k230_final.py` 使用**分段线性**模型：将五个 `cx` 与对应的五个物理厘米值写入 `POSITION_CAL_PX`、`POSITION_CAL_CM`，程序在相邻刻度间插值。这会让每一个实测刻度精确对齐，且保持单调。

二次模型仅作为数据平滑备选：

```text
x_cm = a × cx² + b × cx + c
```

仅在五点数据和独立复测都证明它能降低残差时使用；相机位置、焦距或安装角度变化后必须重新拟合，不可沿用旧系数。

## 4. 回填识别门限

用五点的 `px` 面积数据设定：

```text
BALL_PIXELS_NOMINAL = 五点 px 的中位数（或均值）
MIN_BLOB_PIXELS    = max(3, 最小 px × 0.55)
MAX_BLOB_PIXELS    = 最大 px × 1.80
```

最终取整数。若球位于画面两端时面积变化明显，以两端数据为准适度放宽；不应只按中心点设置很窄的范围。`MAX_ASPECT_RATIO=1.70`、`MIN_ROUNDNESS=0.35` 和 `MIN_QUALITY=50` 先保持不变，只有真实球被稳定漏检时才逐项放宽。

## 5. 标定后验收（仍不接电机）

1. 将球重新放在 `-5、0、+5 cm`，画面与 UART 显示应在各点附近，误差目标不超过 `0.3 cm`。
2. 球在中心静止 30 秒：记录位置标准差，目标不超过 `0.3 cm`。
3. 无球、手电造成强反光、手短暂遮挡、轻振动各测一次：不得连续输出错误的有效位置。
4. 保持 PC 图传连接，K230 `Loop` 仍应不低于 `20 FPS`；此时控制更新率优先于 PC 图传帧率。
5. 将五点表、最终参数、五点残差和测试结果写入 `文档/测试记录表.csv`；再开始 Ti/MG996 的无球中位与方向测试。
