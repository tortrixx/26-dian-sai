# 下一阶段装配与联调清单

当前目标不是立刻让钢球闭环，而是先得到一套安全、可重复的“摆管 + MG996 + Ti + K230”硬件基础。完成本清单后，才进行最终相机标定和钢球闭环。

## 阶段 A：机构与相机安装

- [ ] 水管按题目要求固定为左铰点摆管；确认水管内无色标、传感器或任何改造。
- [ ] 安装端部防落球结构，确保不遮挡相机观测区域；空载手动摆动不干涉车架。
- [ ] MG996 与摆管连杆在中位附近传力最大、两端不进入死点；机械限位先于舵机硬顶。
- [ ] 相机固定在**车架**侧方，近似正对摆管运动平面，覆盖全管段；不要固定在会相对摆管产生未知变形的软支架上。
- [ ] 人工摆到 `-8° / 0° / +8°`，分别保存图像，确认管子和钢球活动带始终在画面内。

完成条件：结构无卡滞，球不会轻易脱落，相机支架与焦距可锁定。

## 阶段 B：电源与布线

- [ ] MG996 采用独立、足够电流能力的电源；不得从 Ti/K230 小板的 5 V 输出直接供电。
- [ ] K230 GND、Ti GND、舵机电源 GND 三者共地；舵机电源正极不反灌 Ti/K230。
- [ ] K230 UART1：IO9(TX) → Ti RX；IO10(RX，可选) ← Ti TX；3.3 V TTL、115200、8N1。
- [ ] 舵机 PWM 信号线接 Ti 定时器通道；确认插头方向、极性和电源线径。
- [ ] 首次通电时让摆管脱开或留足安全行程，手边准备断开舵机电源。

完成条件：舵机动作时 K230 不重启、Ti 不复位、UART 不出现大量乱码。

## 阶段 C：Ti 固件无球联调

以 `../ti_reference/firmware_state_machine_skeleton.c` 为逻辑参考，合入实际 Ti/MSPM0 工程。

- [ ] UART RX 中断或 DMA 调用 `app_uart_rx_bytes(data, length, now_ms)`；记录有效帧、校验失败、序号跳变和超时次数。
- [ ] 100 Hz 定时任务调用 `app_update(now_ms, 0.01f)`；PWM 固定 50 Hz。
- [ ] 实现 `platform_servo_write_us()`，先在无球状态标定中位脉宽、最小/最大脉宽及对应 `±8°`，严禁顶死。
- [ ] 确认控制方向：给定正控制量时，摆管应使球趋向正确方向；若相反，只改 `SERVO_BALL_DIRECTION` 或接线逻辑之一。
- [ ] 保持 `Ki=0`、摆角限幅 `±8°`、角速度限幅启用；未完成保护测试前不得开启正常平衡。

完成条件：可打印 UART 观测状态；空载 PWM 平滑、限位正确、未接到有效视觉帧时自动回中位。

## 阶段 D：失效保护（仍无球）

- [ ] K230 正常发帧时，Ti 可更新最新位置，但不必驱动球闭环。
- [ ] 停止 K230、拔掉 UART、发送错误校验帧、连续无效帧：各情况均在 `200 ms` 内按限速回中位，且不抖动。
- [ ] 断开或重连 PC 图传：Ti 行为不得变化；PC 不得向车端回传控制数据。
- [ ] 保存每项的时间记录/视频。

完成条件：任何视觉或图传故障都不会让摆管维持危险倾角。

## 阶段 E：最终相机标定与静态闭环

仅在阶段 A–D 全部通过后执行：

1. 以最终锁紧的相机位置重新启用 `CALIBRATION_ENABLE`，五点记录 `cx/cy/pixels/quality`。
2. 更新 `POSITION_CAL_PX/POSITION_CAL_CM`、活动带和面积门限；用 `-5/0/+5 cm` 独立复验。
3. 无球、强反光、遮挡、轻振动测试通过后，才接通钢球 PD。
4. 静态控制按 `Kp → Kd` 调整，`Ki=0`；`-5/0/+5 cm` 各 10 次达到标准后，才开放动态 AB。

## 交接给下一位 agent 的最小信息

2. 舵机独立电源规格、接线照片、脉宽—摆角表和方向结论。
3. K230 启动日志、最终安装的 `-8/0/+8°` 截图。
4. 五点标定表、无球/遮挡测试记录，以及任何异常视频。
