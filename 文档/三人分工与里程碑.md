# 三人分工与里程碑

## 分工

### A - 控车

- 循迹传感器标定
- 速度闭环
- 停车线识别
- 计时显示
- 状态机
- 第 2 / 4 / 5 / 6 项行驶逻辑

### B - 视觉与滚球

- 摄像头安装
- 钢球识别
- 像素到厘米标定
- 滤波
- K230 视觉/UART 配置维护
- 扰动补偿
- 测试数据记录

### C - 机械电路与赛务

- 摆杆、凹槽、防落球结构
- MG996 摆管、电源与安全限位
- 电源隔离
- 图传与录像
- 备件
- 报告框架
- 视频归档

## 联调规则

- A 和 B 只改控制闭环。
- C 负责机械、电源、记录和备件。
- 不允许三个人同时改同一个问题。
