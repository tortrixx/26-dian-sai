# 测试与验收清单

> 执行顺序不可跳过：视觉标定 → Ti 安全保护 → 静态滚球 → 动态 AB → 整圈中心 → 指定位置。

## 0. 当前已通过的基线

- [x] K230 启动、UART1 IO9/IO10、640×480 完整管子视场。
- [x] 内部 320×240 传统视觉与 PC 图传同时运行。
- [x] K230 `Loop` 23–27 FPS，PC 图传 6.6–7.8 FPS，近期无 socket stall。
- [x] 图传不参与控制，Wi-Fi 断连不应阻塞 UART。

## 1. 视觉标定（钢球到位后）

- [ ] 相机在中心及允许最大 `±8°` 摆角下拍全管子。
- [ ] `-10、-5、0、+5、+10 cm` 五点采样，拟合 `ZERO_X_PX/PX_PER_CM`。
- [ ] 记录每点 Blob 面积与质量，设置面积范围和 `PIPE_ROI`。
- [ ] 中心 30 s 位置标准差 ≤0.3 cm。
- [ ] 轻振动位置标准差 ≤0.5 cm。
- [ ] 无球、强反光、短遮挡不持续输出错误有效位置。
- [ ] 保持图传时 K230 `Loop` ≥20 FPS。

## 2. Ti/MG996 安全与接口

- [ ] UART 能校验帧头、长度、校验和和序号，只有有效帧更新观测。
- [ ] Ti 以本地接收时刻判断 200 ms 超时。
- [ ] MG996 50 Hz PWM 已示波器验证；中位、上下限和正负方向已记录。
- [ ] K230 停止、UART 拔线、坏帧、连续无球时，摆管在 200 ms 内限速回中位。
- [ ] 球进入端部安全区时，普通目标被覆盖并执行向内救球。

## 3. 静态滚球

- [ ] `+5、0、-5 cm` 各 10 次。
- [ ] 每次 5 s 内稳定。
- [ ] 最终误差 ≤0.8 cm。
- [ ] 首版 `Ki=0`；先调 `Kp`，再调 `Kd`。

## 4. 车辆与动态任务

- [ ] 空载循迹、停车和计时独立通过。
- [ ] 带球动态 AB 10 次至少 8 次全程误差 ≤1 cm。
- [ ] 整圈中心稳定通过后，才开放整圈指定位置。
- [ ] 动态失败优先降车速/摆幅、检查视觉与机械延迟，不直接提高 PID。

## 5. 图传与材料

- [ ] 连续图传 60 s，可清楚看到钢球轨迹和完整管子。
- [ ] PC 录像可回放；记录热点距离、PC FPS、K230 日志。
- [ ] 测试数据填入 `测试记录表.csv`。
- [ ] 设计报告包含协议、标定、保护和任务测试证据。
